# 🏋️ IRONPULSE — Gym Management System

IRONPULSE is a modern **Gym Management System** designed to simplify and organize the daily operations of a fitness center.

The system provides separate experiences for **Administrators and Members**, allowing administrators to manage gym activities while members can access their personal fitness information through a dedicated portal.

## ✨ Features

### 🔐 Admin Authentication

* Admin login system
* Demo admin credentials
* Secure-looking authentication interface
* Logout functionality
* Admin-only dashboard access

### 👤 Member Authentication

* Separate member login
* Member portal
* Personalized member profile
* Membership information
* Attendance information
* Trainer information
* Upcoming class information
* Fitness goal tracking

### 📊 Admin Dashboard

Administrators can manage and monitor:

* 👥 Members
* 🏋️ Trainers
* 📅 Classes
* 💳 Memberships
* 💰 Payments
* ✅ Attendance
* 📈 Gym statistics

### 👥 Member Management

* Add new members
* View member profiles
* Display member profile pictures
* Track membership information
* Monitor member status

### 🏋️ Trainer Management

* Add trainers
* View trainer information
* Assign trainers to members
* Manage trainer records

### 📅 Class Management

* View available classes
* Manage class schedules
* Track class information

### 💳 Membership Management

* Manage membership plans
* Track membership status
* View membership details

### 💰 Payment Management

* Manage payment records
* Track invoices
* Monitor payment status

### ✅ Attendance Management

* Record member attendance
* View attendance information
* Track gym activity
